# Cross a knowledge boundary

Read [knowledge-rule](../knowledge-rule/SKILL.md) for shared principles and
the relevant local routing entries. Distinguish a reference, inbox delivery,
and a change of canonical home; a request for one does not imply the others.

Send only information appropriate to the destination's purpose and audience.
Links, titles, and provenance can also disclose private information. Keep the
full source in its authorized home; use a suitable excerpt when sharing only
part of it. If authority or destination is unclear, resolve that before sending.

Prefer a link plus local context when the object already has the right home.
For a move, verify the destination before removing source content, update known
references, and leave a useful redirect where local conventions support one.
If the destination is unavailable, keep the source and report the pending work.
On retry, check what already arrived before creating another copy.
