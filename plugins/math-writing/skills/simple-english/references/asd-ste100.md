# ASD-STE100 mode

Use this mode only for an explicit Simplified Technical English request.

## Limits

This guide does not contain the official controlled vocabulary. Do not claim
full compliance or invent rule numbers. Tell the user that final compliance
requires the current official ASD-STE100 standard and dictionary.

## Procedure

1. Classify each passage:

   - A procedure gives instructions.
   - A description gives information.

2. Apply the matching form:

   | Form | Procedure | Description |
   |---|---|---|
   | Verb | Imperative | Simple present, past, or future |
   | Sentence length | At most 20 words | At most 25 words |
   | Unit | One instruction per sentence | One fact per sentence; one topic per paragraph |

3. Apply these shared constraints:

   - Use one word for one meaning and one name for one item.
   - Use active voice unless the actor is unknown.
   - Use complete grammar. Do not use contractions or telegraphic fragments.
   - Put each condition before the instruction that depends on it.
   - Avoid participial tails such as “making” or “allowing”; give the action a
     subject in a new sentence.
   - Do not use semicolons. Split the sentence.
   - Keep domain terms as technical names. Keep code and quoted text exact.
   - Use a vertical list only for parallel items. Do not mix facts and
     instructions in one list.

4. Check the result:

   - Count every sentence against its 20- or 25-word limit.
   - Expand contractions.
   - Find `if` and `when`; move a trailing condition before its command.
   - Find synonym groups such as *check/verify/confirm* or
     *configuration/settings*; choose one term unless the meanings differ.
   - Confirm that protected technical text did not change.

Warnings give the command first and the risk second. Notes contain information,
not a hidden instruction or limit.
