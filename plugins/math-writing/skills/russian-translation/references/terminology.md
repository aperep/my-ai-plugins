# Terminology

Use this file only when a term is ambiguous, consistency is being audited, or a
systematic replacement is requested. A project glossary or explicit user choice
always wins.

## Working method

Build a small source-to-target glossary before translating repeated technical
terms. Record uncertain choices separately. Do not silently change an approved
term later in the document, and do not modify this skill's glossary as a side
effect of translating a project.

For a systematic replacement:

1. Find every occurrence and inspect grammatical forms and mathematical uses.
2. Replace by semantic group or section, preserving intentional exceptions.
3. Search again for survivors and for malformed forms of the replacement.
4. Review the diff and compile when applicable.

Raw counts are a check, not proof: Russian inflection and homonyms make blind
replace-all unsafe.
