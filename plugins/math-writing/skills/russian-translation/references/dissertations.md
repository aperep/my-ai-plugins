# Dissertation-specific work

This is conditional project guidance, not part of the author's general voice.
Read the dissertation's own instructions and existing Russian chapters before
using it.

## Structure

Preserve the project's distinction between dissertation-level introduction,
chapter introductions, statements of contribution, and copied source articles.
Do not infer a universal dissertation outline from the calibration article.
When translating a co-authored chapter, preserve `мы` as authorial plural, but
do not invent or relocate a contribution statement.

Treat source-only directories and generated chapters as project data. Discover
them from repository instructions or ask; never assume fixed directory names.

## Personal and administrative text

Grant numbers, affiliations, postal addresses, email addresses, acknowledgments,
and contribution claims are facts, not style samples. Reuse them only when the
user or an authoritative project file confirms that they apply to the target.
Placeholders and old corpus metadata must never become active defaults.

Voice adaptation may change connective prose around confirmed facts, but must
not change the facts themselves.
