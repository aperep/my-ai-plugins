# TinyTeX packages

Install packages as the document needs them; this list is a useful starting point. `tlmgr` will install their dependencies automatically.

```text
adjustbox appendix babel-english babel-russian beamer bookmark booktabs caption
cite cleveref cm-super cmap colortbl comment cyrillic enumitem extarrows
fancyvrb float framed inconsolata jknapltx latexdiff latexmk lh listings
mathtools microtype multirow natbib newtx pgfplots preprint refcheck relsize rsfs
thmtools tikz-cd titlesec tocbibind todonotes ulem unicode-math wrapfig xpatch
xstring xypic
```
