# Trigger tests — dev-finish

## Must load

- “Commit these files and push this branch.”
- “Create a PR for the verified change.”
- “Merge this branch locally, but do not push.”

## Must not load

- “Write a possible commit message.” → ordinary message composition
- “Review this branch without changing it.” → `dev-code-review`
- “Implement the feature.” → `dev-tdd`
