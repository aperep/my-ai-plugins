# Repository maintenance

1. Process the [inbox](INBOX.md): do small unambiguous work, move deferred work
   to the [roadmap](ROADMAP.md), and remove rejected items.
2. Review the roadmap for completed or rejected work and record it in the
   [change log](LOG.md).
3. Run the documentation-tree check.
4. Validate changed plugins using the checks in the [marketplace guide](../README.md).

Report completed work, remaining items, and unavailable checks.
